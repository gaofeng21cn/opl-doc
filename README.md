# OPL Doc

OPL Doc was retired on 2026-08-08. Its durable documentation-governance
workflow now ships as the bundled `$opl-doc` Skill in
[OPL Flow](https://github.com/gaofeng21cn/opl-flow/tree/main/skills/opl-doc).

Install or update OPL Flow through the OPL Framework:

```bash
opl packages install opl-flow
opl packages update opl-flow
```

The standalone Plugin, doctor CLI, native-profile writer, family-plan generator,
templates, and local installer are no longer supported. Repository and domain
truth remain in each owning repository; OPL Flow supplies only the reusable
workflow.

The complete OPL Doc implementation remains available in this repository's Git
history. `fdd01cd443676527b3a72670e2aae4256ff6d051` is the final active-source
commit. Apache-2.0 licensing and the previous-project license notice remain in
the repository root.
